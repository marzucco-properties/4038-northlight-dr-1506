# 4038 Northlight Dr, Unit 1506

Static single-property website for a lake-view condominium in Naples Winterpark IV.

- Production: https://marzucco-properties.github.io/4038-northlight-dr-1506/
- Image pipeline: `npm run images`
- Deterministic build gate: `npm run verify`
- Browser validation: `npm run validate && npm run smoke`

All 57 source photos are retained byte-for-byte under `photos/original/`. Responsive derivatives are regenerated by the inherited Marzucco image pipeline under `scripts/`.
